# 使い方の詳細

README の「使い方」「設定」の詳しい説明。

## 7 ステップの内容

README の図（7 ステップ）の各ステップで、Claude とあなたが行うこと。

1. Claude が、素材（ファイルのパスか本文）・成果物の名前・テンプレートの有無・フッターの文言を聞く。足りない前提（対象者・目的・枚数・欠けている数字）もまとめて聞く。
2. Claude が素材を読み、設計図と原稿を書く。見た目は次の案の選択ページで見て決める。
3. Claude が、全スライドの案と、案の選択ページ（`review.html`）を作り、保存先を伝える。あなたが、そのファイルをブラウザで開く。案の選択ページは、あなたのパソコンの中だけで動く。
4. スライドごとに案を選ぶ。直したい点はコメント欄に書き、よければ「承認」を押す。終わったら「Claude に渡す」を押し、コピーされた内容をチャットに貼り付ける。
5. Claude が、コメントのあったスライドだけを直し、案の選択ページを作り直す。作り直した案の選択ページを開き直して、直したスライドをもう一度承認する。ほかのスライドの承認は残る。
6. 全スライドが承認されると、Claude が PPTX を作る。文字のはみ出しや重なりなどは自動で検査し、Claude が配置を直して作り直す。
7. Claude が、PPTX の保存先と確認用の画像の場所を報告する。確認用の画像は HTML を撮影したもので、PowerPoint の実描画ではない。PowerPoint で開いて最終確認する。

素材が薄いときは、Claude が選択式で質問する。素材にない数字や固有名詞は作らず、「xx」にする。

## 案の選択ページ

ページの上部には、配色の候補とタブがある。

- 「配色」: 全スライドの案の色を見ながら変えられる。
- 「ルール一覧」「縦読み」のタブ: 鉄板ルールの検査結果と、題だけを順に読んだ流れを確かめられる。
- 人の確認が要る項目（数字・機密・決定事項）: 各スライドのチェックを入れてから承認する。

## 設定の補足

- 基調色は 1 色、強調色は 1〜2 色で、指定がなければテンプレートの色になる。
- テンプレートは、16:9（13.33×7.5in）で、題と本文の領域があるレイアウトを持つ `.potx`・`.pptx` が条件。使うのは表紙・本文・裏表紙の 3 つで、フォントは変わらない。登録を消しても、作成済みの成果物には影響しない。
- 題・リードの文字は、BIZ UDPゴシック固定・左寄せ。サイズの変え方は、Claude に頼む。本文は 14pt、注記は 10pt が下限。

## 承認が断られるとき

次のメッセージは、承認のあとにスライドの内容が変わった、または古いページ・古いタブから「Claude に渡す」を押したときに出る。

- 「承認のあとで断片が変わっています」（`finalize` が止まる）
- 「古い形式の承認のため、断片の指紋がありません」
- 「古い断片を承認しています」「fr がありません」（`choices-import` が断る）

案の選択ページを作り直し、開き直して、新しい断片を見てもう一度承認する。「Claude に渡す」を押して、Claude に貼り付ける。ほかのページの承認は、同じブラウザなら残る。
