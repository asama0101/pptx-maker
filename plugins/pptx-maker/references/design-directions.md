# デザイン方向（案のレイアウトの指針）

読むとき: create の 3 章で、案を書く前。何のための手順書か: 案（`NN-R1`〜`NN-R4`）のレイアウトを設計する。どのページも 2〜4 案を書き、案ごとにレイアウトの違いで名前を付けて（例: 左に結論枠と根拠 3 点）、断片の `data-variant` に書く。どの案にするかは、利用者が `review.html` でスライドごとに選ぶ。全体の「方向」は決めない。下の 3 章のカタログは、案のレイアウト例の一覧として使う。

案は、**色・書体・装飾を変えない**。変えるのは、構図・密度・主役の種類・図の使い方・余白・視線の流れである。色は設計図の基調色・強調色のまま（色の規約は、同じ 3 章で読む HTML の書き方の規準）。題・ヘッドメッセージの帯の位置と大きさ、出典の位置は固定。`chromeSpec` が題・ヘッドの文字の規約（大きさ・フォント・配置）を、`keepout` がテンプレートのヘッダー・フッター領域との重なりを検査する。案が変えられるのは、その内側の本体の領域である。

## 1. 使う観点と使わない観点

PPTX に出せる観点だけを使う。

**使う観点**
- 構図: どこに何を置くか。主役を 1 つ決め、ほかは従にする。
- 余白: 主役の周りは空ける。無所属の空白帯は残さない（本体は領域の下端近くまで使う）。
- 強弱: 大きさ・太さ・濃淡で順位をつける。強調色は 1 ページ 1〜2 か所（機械は強調色の要素が 7 個以上で警告。R22）。
- 視線の流れ: Z の法則。始点（題・結論）は左上、終点（決定・結論）は右下。
- 文字の階層: 見出し・本文・注記の大きさと太さを `data-role` と `var(--fs-*)` で分ける。
- 案どうしの構成の違い: 構図と主役の種類を変える。

**使わない**
- グラデーション・影・ぼかし・アニメーション・ホバーなどの動き。
- Web フォント。
- 背景画像・ノイズ・模様。
- 色の独自の選び方（色は設計図の基調色・強調色）。
- `pp-*` 以外の部品（PPTX に出ない）。

## 2. 案の選び方

1. 設計図の題材（稟議・承認、提案、計画、障害報告、そのほか）と、読み手（決裁者・現場・顧客など）を確かめる。
2. ページごとに、下の 3 章のカタログから、そのページの主張をよく見せるレイアウトを 2〜4 つ選び、案にする。利用者には聞かない（見た目は `review.html` で見てから選ぶ）。依頼に希望があれば反映する。
3. **本体の構図は、ページごとに設計する**。カタログの例を全ページに当てはめない。

## 3. 案のレイアウト例のカタログ

密度は 1 枚の本体の文字量の目安（見出し・注記を除く）。目安であり、検査はない。Z の始点は左上の題、終点は書いた位置。

### 稟議・承認（読み手: 決裁者・経営会議）

- **決定先行型**
  - 向く題材: 一括承認、投資判断。結論と求める決定を先に見せたいとき。
  - 主役: 決定の枠（決めること・期限・推奨）。根拠は右か下に 3 点まで。
  - 密度: 100〜200 字。図は根拠の 1 つだけ。
  - 余白と配置: 決定の枠を大きく、根拠は小さな 3 区画に分ける。
  - 視線: 始点は題、終点は右下の決定の枠。
  - 避ける: 全ページを決定の枠で始めること（決定は 1 か所に書く。R18）。
- **比較表中心型**
  - 向く題材: 案の選定、ベンダー比較。評価軸が明確なとき。
  - 主役: 評価軸×案の表。推奨の列だけ強調。
  - 密度: 150〜250 字。表は 5 行 4 列まで。
  - 余白と配置: 表を左 2/3、判断の理由を右 1/3 か下の帯に置く。
  - 視線: 始点は題、表の推奨列を通り、終点は右下の判断の枠。
  - 避ける: 全セルを同じ重みで並べること。
- **数字と推移型**
  - 向く題材: 効果・コストの説明。数字の変化が主張のとき。
  - 主役: 1 つの数字と、それを支えるグラフ（推移・内訳）。数字だけを大きくして終わらせない。
  - 密度: 60〜120 字。グラフは本体の半分以上。
  - 余白と配置: グラフを主、数字は図の中の注目点に置く。
  - 視線: 始点は題、終点は右下の数字の含意。
  - 避ける: 「大きな数字＋小さなラベル」を 3 つ並べるだけのページ。
- **流れ図中心型**
  - 向く題材: 手順の変更、承認後の進め方。段階・因果が主張のとき。
  - 主役: 現状→課題→対策→効果の流れ（矢印つき）。
  - 密度: 100〜180 字。各段に定量を 1 つ。
  - 余白と配置: 段を横に並べ、強調の段だけ濃く。下に含意の 1 文。
  - 視線: 始点は左上の段、終点は右下の効果。
  - 避ける: 矢印のない箱の並び。

### 提案（読み手: 顧客・上長）

- **課題と解決の対比型**
  - 向く題材: 現状の問題と提案の対応を見せたいとき。
  - 主役: 左右の対比（課題と打ち手）。対応が 1 対 1 で見える線か番号を付ける。
  - 密度: 120〜200 字。
  - 余白と配置: 左右 2 分割に頼りすぎない。全ページの 3 割までにし、ほかは別の構図にする。
  - 視線: 始点は左の課題、終点は右下の効果。
  - 避ける: 左右を同じ重みで置くこと（右の打ち手を主にする）。
- **全体像と要所の拡大型**
  - 向く題材: 構成・体制・仕組みの提案。
  - 主役: 全体の構造図（絵か図形）と、注目部分の拡大。
  - 密度: 60〜120 字。文字は図の中の語が中心。
  - 余白と配置: 全体を左、拡大を右下。拡大の元は枠で示す。
  - 視線: 始点は全体の入口、終点は拡大した要所。
  - 避ける: 全体図に全要素を同じ強さで書くこと。
- **ロードマップ型**
  - 向く題材: 段階導入、移行の提案。
  - 主役: 時間軸の帯と、段階ごとの到達点。
  - 密度: 100〜180 字。
  - 余白と配置: 横軸を時間、縦軸を工程・担当にして格子で置く。
  - 視線: 始点は左端の現在、終点は右端の到達点。
  - 避ける: 段階の数が 5 を超えること。
- **実績の証拠型**
  - 向く題材: 効果・実績で説得するとき。
  - 主役: 実績の表またはグラフ（事例×指標）。
  - 密度: 150〜250 字。
  - 余白と配置: 表を主、事例の要点を表の下の帯に置く。
  - 視線: 始点は題、終点は表の比較の基準（R30）。
  - 避ける: 数字に比較の基準がないこと。

### 計画（読み手: 実行する人・管理者）

- **工程帯型**
  - 向く題材: 全体スケジュール。
  - 主役: 時間軸の帯（ガント）。判断点と現在位置を強調。
  - 密度: 100〜180 字。
  - 余白と配置: 左に工程名、右に期間。判断点だけ強調色。
  - 視線: 始点は左上の工程、終点は右下の最後の判断点。
  - 避ける: 全工程を同じ濃さにすること。
- **判断点中心型**
  - 向く題材: 段階審査・撤退条件がある計画。
  - 主役: 判断点とその基準（数字）。工程は従。
  - 密度: 100〜160 字。
  - 余白と配置: 判断点を大きな節として横に並べ、基準を節の下に置く。
  - 視線: 始点は最初の判断点、終点は最後の判断点。
  - 避ける: 基準がない判断点。
- **体制と役割型**
  - 向く題材: 体制図、責任分担。
  - 主役: 役割×担当の表、または組織図。
  - 密度: 120〜200 字。
  - 余白と配置: 責任者の行・列だけ強調。
  - 視線: 始点は責任者、終点は右下の連絡・承認の経路。
  - 避ける: 担当のない役割、役割のない担当。
- **目標の分解型**
  - 向く題材: 目標を施策に落とすとき。
  - 主役: 目標から指標・施策へ分かれる木（ツリー）。
  - 密度: 100〜160 字。
  - 余白と配置: 左に目標、右へ分解。切り口は 1 つにそろえる（R04・R05）。
  - 視線: 始点は左の目標、終点は右下の施策。
  - 避ける: 階層ごとに切り口が変わること。

### 障害報告（読み手: 管理者・関係部門）

- **時系列中心型**
  - 向く題材: 発生から復旧までの説明。
  - 主役: タイムライン（時刻・事象・対応）。
  - 密度: 100〜180 字。
  - 余白と配置: 横軸を時刻にし、影響が出た区間だけ強調。
  - 視線: 始点は発生、終点は右の復旧。
  - 避ける: 時刻のない事象。
- **影響範囲の図型**
  - 向く題材: 構成のどこで何が起きたかの説明。
  - 主役: 構成図の絵（`pp-picture`）に、障害点と影響の範囲を重ねたもの。
  - 密度: 40〜100 字。文字は注釈に絞る。
  - 余白と配置: 絵を大きく、番号つきの説明を右に置く。
  - 視線: 始点は障害点、終点は影響の先。
  - 避ける: 絵の中に長い文を入れること。
- **原因と対策の対応型**
  - 向く題材: 原因が複数あり、対策との対応を見せたいとき。
  - 主役: 原因→対策の対応表（因果の矢印または行の対応）。
  - 密度: 150〜220 字。
  - 余白と配置: 左に原因、右に対策、行ごとに対応する。
  - 視線: 始点は左上の根本原因、終点は右下の対策の期限。
  - 避ける: 原因と対策の数が合わないこと。
- **再発防止の一覧型**
  - 向く題材: 対策の実施状況を管理者に見せるとき。
  - 主役: 対策一覧（事項・内容・期限・担当・状態）。
  - 密度: 150〜250 字。
  - 余白と配置: 状態の列だけ強調。期限が近い行を先頭に。
  - 視線: 始点は題、終点は右下の完了予定。
  - 避ける: 期限と担当のない行。

### そのほか（採用・新規事業・研修など）

- **場面と人の型**
  - 向く題材: 採用、研修、社内の取り組み紹介。
  - 主役: 人・場面を表す絵やアイコンと、段階の流れ。
  - 密度: 60〜120 字。
  - 余白と配置: 余白を広く取り、1 ページ 1 場面にする。
  - 視線: 始点は左上の場面、終点は右下の次の行動。
  - 避ける: 利用者の素材にない写真・人物の追加。
- **市場から打ち手へ型**
  - 向く題材: 新規事業の構想。
  - 主役: 市場規模→狙う領域→打ち手の絞り込み（階段・漏斗の図）。
  - 密度: 100〜180 字。数字は前提を明記した試算か「xx」。
  - 余白と配置: 左上に広い市場、右下に狙う領域を置く。
  - 視線: 始点は市場、終点は右下の打ち手。
  - 避ける: 素材のない数字。
- **カリキュラムの表型**
  - 向く題材: 研修、講座のプログラム。
  - 主役: 時間割・単元の表（時間×内容×到達点）。
  - 密度: 150〜250 字。
  - 余白と配置: 行を同じ高さにそろえ、到達点の列だけ強調。
  - 視線: 始点は最初の単元、終点は最終の到達点。
  - 避ける: 到達点のない単元。
- **指標一覧型**
  - 向く題材: 活動の結果の報告。
  - 主役: 指標の表と小さなグラフ（同じ軸でそろえる）。
  - 密度: 100〜200 字。
  - 余白と配置: グラフを 2〜3 個並べ、目標との比較を添える（R30）。
  - 視線: 始点は題、終点は右下の総括。
  - 避ける: 軸のそろっていないグラフの並び。

## 4. 見本をなぞらない

案を書くとき、題・ヘッドの帯・チャートタイトル・注の位置は固定で、どのページも似る。本体の構図が定石に収束すると、全ページが同じに見える。次を守る。

- 1 ページずつ、ヘッドの主張を一番よく見せる本体の構図を設計する。`assets/components/` の見本の配置を写さない。
- 同じ構図を続けない。隣り合う 3 ページで、本体の構図（左右 2 分割、表、グラフ、流れ、絵、格子）を変える。左右 2 分割は、全ページの 3 割までにする。
- 「大きな数字＋小さなラベル」の並びに頼らない。数字を大きくするときは、比較の基準（目標・前年・他案）とグラフか表を添える。1 ページ 1 か所までにする。
- 案どうしは、構図と主役の種類を変える。同じ構図の位置違いにしない。
- 前のページで選ばれた案の傾向は、全ページを同じ構図にする理由にはならない。ページの主張が違えば、構図も変える。
- 案を書いたら、ページごとの構図（表・グラフ・流れ・絵・格子・左右）を一覧にして、偏りを確かめる。
